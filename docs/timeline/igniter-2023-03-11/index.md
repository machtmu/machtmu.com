# Igniter and Thermocouple Tests - March 11th, 2023

Several igniter designs and thermocouple locations were tested to compare ignition behaviour and temperature measurements.

## Result

Surviving plots show reported peaks near 880 °C for one igniter and roughly 300 °C at an injector-mounted sensor. Corrupted `-9999` records and uncertain sensor placement were discussed afterward, so these plots document the campaign but should not be treated as definitive igniter-performance measurements.
