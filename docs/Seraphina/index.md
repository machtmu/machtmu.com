# Seraphina

Seraphina is MACH's project for 2026. It was a complete overhaul of the tank system with automated fueling. At Launch Canada, MACH was able to press a single button and have the system load both fuel and oxidizer, fire the engine, and safe the pad. The only manual steps were opening the cylinders and setting the regulators.
