# SPRINT Cold Flow Test - November 20th, 2025

On November 20th, 2025, we completed another cold flow while continuing to develop the team's test operations. The control software received another major overhaul, and the test came close to being scrubbed.

Four team members prepared the hardware while two set up mission control, which operated from the design zone for the entire test. The campaign focused more on team integration than data collection. Training new members while running a test is difficult, so each campaign helps make the process more repeatable. We also tested a Twitch livestream and continued developing the software toward a true multi-operator workflow. [Read the debrief](nov-20-coldflow/debrief.md).
