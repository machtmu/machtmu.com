# SPRINT Hot Fire Test - September 13th and 14th, 2025

On September 13th, we set up and attempted a hot fire, then accidentally ran a cold flow, all in one day. We did not rent cars, and propellant was our only expense. The test site is about 90 minutes from TMU. We were proud of the team's pace, but the hot-fire attempt did not produce data; only the cold flow did. The ignition failure remains unexplained. Inspection showed that neither the igniter nor the e-match fired.

On Sunday, September 14th, we returned, completed another hot fire, and collected hot-fire data for the first time.
