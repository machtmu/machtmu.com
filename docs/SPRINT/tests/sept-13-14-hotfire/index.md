## Test Overview

This multi-day testing campaign marked a significant milestone in SPRINT development, with successful hot-fire tests conducted on both September 13th and 14th. The tests validated system improvements and demonstrated consistent engine performance across multiple firing sequences.

## Key Achievements

- **Successful Multi-Day Campaign**: Demonstrated system readiness and reliability across consecutive test days
- **Consistent Performance**: Both tests showed stable combustion and expected engine behavior
- **System Validation**: Confirmed improvements made since previous test campaigns
- **Operational Readiness**: Validated procedures and safety protocols for sustained testing operations

## Test Conditions

- **Date**: September 13th & 14th, 2025
- **Location**: MACH Test Facility
- **Propellants**: Ethanol and Nitrous Oxide
- **Test Type**: Static Hot-Fire
- **Duration**: Multiple firing sequences across two days
